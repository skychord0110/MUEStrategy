# 接続断による午後欠損の if 分析 2026-09-03

**要旨:** 13:04:34 にkabuステーションが落ち、以降大引けまで再接続できず、
runnerは午後の板PUSHを1件も受信しなかった。よって13:04以降のストラテジー検知・
仮想売買ログは存在しない。板シグナルは遡及取得できず**実際の午後トレードは復元不能**なので、
Yahoo Finance 5分足（週次検証と同じ参照データ）で午後の値動きを取得し、板トリガーの
価格代理（安値圏タッチ）で「もしrunnerが動いていたら」を推計した。

**結論:** 午後は弱い地合い（再開値より高値引けは50銘柄中13＝**26%**、最大上昇+1.9%）。
引け戻り系は大半が大引けで小幅マイナス着地の推計で、**大きな取り逃しは無い**。むしろ
実弾対象の `afternoon_reversal` も推計で純**-0.38%**のため、断は小さめの負けを回避した公算が高い。
ただし本推計は価格代理であり、実ライブとは必ずずれる（下記「限界」）。

---

## 1. 障害の事実（ログから確定）

| 時刻 | 事象 |
|---|---|
| 〜08:17 | 夜間からの長時間断（996分）。08:17:14 runner再起動・認証成功・50銘柄登録 |
| 09:00〜13:04:34 | **接続OK・正常に検知/仮想売買を記録**（この間は実データ） |
| **13:04:34** | WebSocket切断（`WinError 10054`＝kabuステーション消滅。PCメモリ不足＝既知事象） |
| 13:04〜大引け(15:30) | **再接続できず板PUSHゼロ**。以降ログは接続エラー行のみ |
| 〜19:18 | 断が継続（当該調査時点でも未復旧） |

- 13:04時点で**仮想建玉・実建玉ともにゼロ**。したがって「大引け補完で閉じるべき
  未決済ポジション」は存在せず、runner本ログに追記すべき手仕舞い行は無い。
- 実弾（autotrade, `dry_run=false`）の対象は `afternoon_reversal` のみ。エントリー窓は
  13:00〜だが切断が13:04で、発注前。口座は終日 保有0件・買付可能額198,429円。

## 2. 午前の実績（09:00〜13:04・実データ）

- UNDER急増: **79件 / 31銘柄**（下値大口買いの検知。afternoon系のエントリー種）。
  → 午後も同ペースで出ていたはず＝afternoon_reversalは午後に複数回エントリーしていた可能性が高い。
- 仮想売買の往復: **4840 投げ売り反発 09:11:52 @754 → 09:12:44 利確 @772（+2.39%）**（決済済み）。
- 4013 は前営業日建玉の「大引け(補完)」決済 +0.30%（当日エントリーではない）。

## 3. 午後の if 推計（価格代理トリガー・往復0.15%控除後）

方式: 板の「UNDER急増（安値圏で下値に大口買い）」を **安値圏タッチ**（現在値が当日安値の
low_zone_pct=1%以内）で代理。約定は**次の5分足始値**（先読み排除）、決済は実戦略と同じ
**損切り-SL% / 利確+TP% / 大引け(15:30)**、同一足でSL・TP両方に触れたらSL優先（不利側）。
対象は13:05以降のエントリーのみ（09:00〜13:04は実データで欠損なし）。

| 戦略（実弾/仮想） | SL/TP | n | 勝率 | 平均純益 | 利確/損切/引け |
|---|---|---|---|---|---|
| afternoon_reversal（**実弾**） | -2/+2 | 27 | 37.0% | **-0.38%** | 1/3/23 |
| afternoon_reversal_ranked（仮想） | -2/+2 | 27 | 40.7% | -0.30% | 1/3/23 |
| vwap_discount_reversal（仮想） | -2/+2, 乖離≥1% | 12 | 58.3% | -0.30% | 1/3/8 |

- いずれも**大半が大引け決済**（TP+2%/SL-2%に届かず小幅で引け）。afternoon_reversalの
  分布は best +1.85% / worst -2.15% / 中央値 -0.15%。
- `vwap_discount_reversal` はVWAP-1%以上の押しに限定するぶん選別的で勝率は高い（58%）が、
  純益はやはり小幅マイナス。この弱い地合いでは「押し目買い」がほぼ報われなかった。
- `panic_rebound`（投げ売り反発, 09-15）は午後の投げ売り検知が板依存で価格代理の信頼度が
  低いため定量推計から除外。午後に-2%超の急落は数銘柄あったが（4840 -4.6%等）、
  反発の有無は板無しでは判断不能。

## 4. 午後の地合い（参照データ）

- 50銘柄中、引けが13:05再開値より高い銘柄は **13（26%）** のみ＝**弱い午後**。
- 最大上昇 9337 +1.91% / 5034 +1.03%。下落は 4840 -4.63%、4199 -2.56%、6433 -2.38% など。
- 上昇の裾が薄く（+2%到達がほぼ無い）、押し目買いのTP+2%がほとんど発火しなかったのが
  純益マイナスの主因。

## 5. 実務上の含意

- **取り逃しは軽微〜むしろプラス。** 断が無くても午後の引け戻り系は概ね小幅マイナスの推計。
  実弾 `afternoon_reversal` も -0.38%/件のため、断は小さめの負けを避けた可能性が高い。
- ただし実弾は買付可能額198,429円＝**実建玉は1〜2銘柄程度**に制限され、推計の27件がそのまま
  実損益になるわけではない。影響額は小さい。
- 恒久対策は既知の**PCメモリ不足**（kabuステーション自動落ち）。ここは今回の分析対象外だが、
  同種の午後全欠損を繰り返さないための根本対応が本質。

## 6. 限界と注意（必読）

- **午後の実トレードは復元していない。** 上表は「安値圏タッチ」を板トリガーの代理にした
  **推計**で、実ライブとは必ずずれる。実検知はOVER/UNDERの不均衡・歩み値も見るため代理より
  選別的で、代理は弱い地合いで「単に安値を更新した銘柄」を拾いやすく**件数を過大・純益を
  下振れさせる**傾向がある。数字は「方向感」まで。
- 5分足は約定粒度が粗く、足内のSL/TP到達順は不明（不利側に倒して処理）。始値約定は
  楽観側になり得る。
- 資格の但し書き: 本分析は投資助言ではない。

## 7. 週次集計への反映（本ログへ直接追記）

if推計トレードを日次の **`strategies/runner/logs/runner_2026-09-03.log`（本ログ）末尾に直接追記**した
（ユーザー指示）。週次集計 `weekly_report.py` はこのファイルを走査するのでそのまま集計へ載る。

- 追記: 66トレード（`AI午後引け戻り`27 / `(順位優先)`27 / `AI VWAP乖離反発`12）。
  前後を `# ==== ここから/ここまで if推計 ====` の注記で挟み、各行のトリガーに **`[IF補完]`** を付与。
- 安全策: 稼働中プロセスが同ファイルに書き続けているため **O_APPEND（末尾原子追記）** で足した。
  既存行の上書き・巻き戻しはしない。UTF-8(BOMなし)・CRLFで本ログに一致。再実行しても
  `[IF補完]` 検出でスキップし二重追記しない。
- 検証: `weekly_report.parse_trades()` で 2026-09-03 が **67件**（実約定1＝午前4840 +2.39%
  ＋ if補完66）として正しくバケット化されることを確認済み（週 2026-W36）。
- 生成/再追記: `python analysis/afternoon_gap_sim.py --date 2026-09-03 --outage-from 13:05 --emit-log`
- **取り消したい場合**は本ログ内の `# ==== ここから if推計` 〜 `# ==== ここまで if推計 ====`
  ブロックを削除する（`[IF補完]` を含む行が目印。実約定行には付かない）。
