# 新シグナルの探索と採用 2026-08-29

目標: **需給ベースのデイトレ戦略を新規に作り、直近20営業日で勝率70%以上**。

結論: **「VWAP乖離反発」を採用。直近20営業日 n=37・勝率78.4%・期待値+0.79%。**
仮想売買として実装済み。実発注には入れていない。

---

## 1. 検証の設計

| | |
|---|---|
| 銘柄 | 128銘柄（`extracted_stocks/*.csv` 7本の和集合） |
| 期間 | 2026-07-01〜08-28（41営業日） |
| 判定期間 | **直近20営業日**（07-31〜08-28）＝目標を測る対象 |
| 検証期間 | それ以前 21営業日（07-01〜07-30）＝後から見つけた条件が通用するかの確認 |
| 株価 | Yahoo Finance 5分足（出来高込み・口座には触れない） |
| コスト | 往復0.15%控除 |

**先読みの排除**: シグナルの判定にはその足までの情報しか使わない。約定は
**次の足の始値**。利確と損切りに同じ足で両方触れたら損切りを先とする（不利側に倒す）。

**勝率だけを追わない**: 利確を小さく損切りを大きくすれば勝率はいくらでも上がる。
採用の条件を「勝率70%以上 **かつ 期待値プラス** かつ n≥15」とした。

---

## 2. まず全滅した案 — 5分足だけでは需給が読めない

価格と出来高だけから需給を読む5案を作り、判定期間で評価した。

| 案 | 読み | 件数 | 勝率 | 期待値 |
|---|---|---:|---:|---:|
| 売り吸収 | 出来高を伴う下ヒゲが安値圏 | 454 | 45.4% | −0.10% |
| 売り枯れ | 安値圏で出来高が細る | 418 | 48.3% | −0.06% |
| VWAP奪回 | 出来高を伴ってVWAPを上抜く | 351 | 45.3% | −0.13% |
| 下値切り上げ | 押し安値が当日安値を切り上げ | 1090 | 48.3% | −0.03% |
| 寄り安の切り返し | 始値を出来高を伴って回復 | 176 | 43.8% | −0.14% |

**5案とも勝率45〜53%、期待値マイナス。** 既存のUNDER急増（午後67.6%）に遠く及ばない。

**得られた知見: 板の厚みは価格と出来高には写らない。** UNDER急増が見ているのは
「まだ約定していない買い注文の積み上がり」であり、これは歩み値には現れない。
5分足から需給を読もうとしたこと自体に無理があった。

再現: `python analysis/research_signals.py`

## 3. 採用案 — 板 × 歩み値の二段確認

方針を変え、**板のシグナルを土台に、歩み値からの確認条件を重ねる**構成にした。

土台: 午後（13時〜）のUNDER急増・500円以上・利確+2%/損切り−2%（既存分析で最良の決済）

確認条件を1つずつ足して、判定期間と検証期間の両方で効くものを探した。

| 追加条件 | 判定期間 | 検証期間 |
|---|---|---|
| **VWAPを1%以上下回る** | n=37 **78.4%** +0.79% | n=18 **83.3%** +0.76% |
| 直近5本で2%以上下落 | n=17 88.2% +1.02% | n=7 71.4% +0.12% |
| 直近5本で1%以上下落 | n=30 80.0% +0.74% | n=14 71.4% +0.28% |
| 13時台のみ | n=39 74.4% +0.43% | n=20 75.0% +0.36% |
| 出来高が中央値の2倍以上 | n=36 72.2% +0.34% | n=18 77.8% +0.47% |
| 当日安値圏（下から20%） | n=50 70.0% +0.52% | n=21 71.4% +0.48% |
| （条件なし＝土台） | n=72 68.1% +0.35% | n=28 71.4% +0.39% |

**VWAP乖離を選んだ理由**: 期待値が最も高く、件数も高勝率群では最大で、
**検証期間のほうがむしろ成績が良い**（83.3%）。後から見つけた条件が別期間で
再現するのは、偶然の当てはめではないことを示す最も強い証拠。

再現: `python analysis/research_combo.py`

## 4. 過剰適合でないことの確認

20営業日の標本に条件を探し回れば、何かは必ず当たる。以下4点を確認した。

### しきい値を動かすと、なめらかに変わるか

| VWAP乖離 | 判定期間 | 検証期間 |
|---|---|---|
| 0%以下 | n=68 69.1% +0.37% | n=27 74.1% +0.45% |
| −0.5%以下 | n=52 73.1% +0.56% | n=23 73.9% +0.45% |
| **−1.0%以下** | n=37 **78.4%** +0.79% | n=18 **83.3%** +0.76% |
| −1.5%以下 | n=25 84.0% +0.89% | n=11 81.8% +0.81% |
| −2.0%以下 | n=13 84.6% +1.14% | n=7 71.4% +0.54% |

**単調に改善している**（判定・検証の双方）。ある1点だけ跳ね上がるなら
その値に合わせただけの疑いが濃いが、そうなっていない。

### 週ごとに安定しているか

7週すべて期待値プラス（+0.19 / +0.39 / +0.30 / +0.69 / +0.92 / +0.94 / +1.13%）。
勝率は50〜93%とばらつくが、**特定の1週が全体を作ってはいない**。

### 銘柄が偏っていないか

55件が**29銘柄**に分散。上位3銘柄で22%（最多でも4件）。
先週の「定期買い集め」が6銘柄・上位3で88%だったのとは対照的。

### 決済ルールを変えても残るか

| 決済 | 勝率 | 期待値 |
|---|---:|---:|
| 利確+2%/損切り−2% | 80.0% | +0.78% |
| 利確+3%/損切り−2% | 78.2% | +0.79% |
| 利確+1.5%/損切り−1.5% | 78.2% | +0.65% |
| 大引けのみ | 78.2% | +0.73% |
| 利確なし/損切り−2% | 76.4% | +0.65% |
| 利確+2%/損切り−1% | 61.8% | +0.41% |

6通り中5通りで76〜80%。1つの出口に依存していない。
損切り−1%だけ落ちるのは、既存分析と同じ「浅い損切りは反発前の押しで刈られる」現象。

### フィルタが実際に選り分けているか

| | 件数 | 勝率 | 期待値 |
|---|---:|---:|---:|
| 土台すべて | 100 | 69.0% | +0.36% |
| **通した側**（VWAP−1%以下） | 55 | **80.0%** | **+0.78%** |
| **除外した側** | 45 | 55.6% | **−0.15%** |

**除外された側が期待値マイナス。** ノイズを削って良い側だけを残せている。

再現: `python analysis/research_verify.py`

## 5. 需給としての読み

| 情報源 | 見ているもの |
|---|---|
| UNDER急増（板） | 下値に**大口の買い注文が積まれた** |
| VWAP−1%以下（歩み値） | その日の**平均取得コストより1%以上安い** |

重なるのは「売られ過ぎた水準に、大口の買いが待っている」状態。
その日に買った人の平均より安く、かつ下値には受けが控えている。

## 7. 限界

- **フォワードの実績はまだ0件。** 上の数字はすべて過去データの当てはめ。
- **VWAPの算出方法が検証と実運用で一致しない。** 検証はYahooの5分足由来、
  実運用はPUSHのティック積み上げ。後者のほうが細かいが、寄り付きの板寄せぶんを
  寄り値で概算するなどの差がある。**まず仮想売買で、検証どおりの成績が出るかを確認する。**
- **土台のUNDER急増に依存している。** 独立した新シグナルではなく、既存の板シグナルに
  歩み値の確認を足した複合。UNDER急増が機能しなくなれば道連れになる。
- 期間は41営業日のみ。うち検証期間は21営業日で、地合いの寄与は分離していない。
- 仮想売買は指値の約定可否を考慮していない。実弾ではそのぶん落ちる。
- 私は投資助言の資格を持たない。売買の判断は利用者が行うこと。
